# CineAPI

CineAPI é uma API REST completa para gerenciamente de filmes, oferecendo funcionalidades como: <br>
 📌 Cadastro, edição, exclusão, busca e filtragem de filmes.  <br>
 📌 Sistema de autenticação com registro e login. <br>
 📌 Geração de **TOKEN JWT** no login, com tempo expiração. <br>
 📌 Sistema de roles de acesso, com **user** e **admin**, que controlam as permissões do usuário. <br>
 📌 Possibilidade do usuário favoritar seus filmes preferidos. <br>

## 🚀 Tecnologias 
 - Java
 - Spring Boot
 - PostgreSQL
 - HTML
 - CSS
 - JavaScript
 - Bootstrap
